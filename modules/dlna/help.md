**Где это:** плитка «DLNA» на /apps (оверлей).

- Просмотр медиасерверов DLNA/UPnP в локальной сети: SSDP-скан, навигация по папкам, URL файла для воспроизведения.
- На панели работает `minidlna` (`:8200`) — собственная библиотека `/srv/media` тоже видна как сервер.
- API: `POST /api/dlna/scan`, `GET /api/dlna/content?ip=<сервер>&id=<object_id>`, `GET /api/dlna/file_url?...`.
- Сначала «Сканировать» — без выбранного сервера content вернёт `No IP`.
- Выключенный модуль: плитка скрыта, `/apps/dlna` и `/api/dlna` → 404.

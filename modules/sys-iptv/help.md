**Где это:** блок «IPTV» на вкладке «Система» + плеер IPTV.

- Загрузка m3u-плейлистов по URL.
- Добавление, удаление, редактирование плейлистов; включение/выключение.
- Автоматическое обновление плейлистов по расписанию.
- Скачанные плейлисты хранятся в `/srv/media/IPTV` (видны в Samba/DLNA).
- Выключенный модуль: блок скрыт.

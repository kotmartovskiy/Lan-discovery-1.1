**Где это:** плитка «Заметки» на /apps (оверлей).

- Текстовые заметки: создание, редактирование, удаление, поиск по списку.
- Двухпанельный Markdown-редактор с предпросмотром результата в реальном времени.
- API: `GET /api/notes`, `POST /api/notes` (JSON `title`, `content`), `PUT/DELETE /api/notes/<id>`.
- Данные хранятся в БД панели (`devices.db`), бэкап — см. «Система» → Backup БД.
- Выключенный модуль: плитка скрыта, `/apps/notes` и `/api/notes` → 404.

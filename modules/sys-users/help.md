**Где это:** блок «Пользователи» на вкладке «Система».

- Три роли: `admin`, `user`, `guest` — role-based access control.
- Добавление, удаление, смена роли и пароля; включение/выключение учёток.
- Управление пользователями — только для роли admin.
- Выключенный модуль: блок скрыт, управление пользователями недоступно.

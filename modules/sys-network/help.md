**Где это:** блок «Сеть» на вкладке «Система».

- Проверка сетевой связности: тестовые адреса (шлюз, DNS, провайдер).
- Зоны RU, настройка и проверка тестовых адресов (кнопка «Изменить»).
- Статусы проверок: доступен/недоступен, время ответа.
- Выключенный модуль: блок скрыт, сетевые проверки недоступны.

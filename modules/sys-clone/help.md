**Где это:** блок «Клонирование / HDD» на вкладке «Система».

- Клонирование eMMC ↔ SD, проверка готовности носителей перед клонированием.
- **Клонирование eMMC → SD отключено, пока система загружена с SD-карты** —
  `dd` перезаписал бы работающую систему; панель показывает причину отказа.
- Рекомендации: разделы SD не должны быть смонтированы, HDD подключён для хранения данных.
- Выключенный модуль: блок скрыт.

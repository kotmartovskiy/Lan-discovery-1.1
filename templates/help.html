1. Обзор проекта

Веб-панель управления домашней инфраструктурой на базе {{ hf.board }} ({{ hf.os }}, hostname {{ hf.hostname }}). Единое приложение (Flask + SQLite) для мониторинга сети, устройств, погоды, валют, управления мультимедией, встроенных утилит и игр.

Технологии

  • Сервер: Python 3 + Flask (порт {{ hf.port }})
  • База данных: SQLite (/opt/lan-discovery/devices.db)
  • Сканирование сети: nmap (ARP-сканирование)
  • Погода: Open-Meteo API ({{ hf.coords }})
  • Валюты: CoinGecko + Frankfurter + Yahoo Finance
  • Модули: вкл/выкл разделов, установка зависимостей — страница «Модули»
  • Системный сервис: lan-discovery.service (systemd)

4. Погода и мониторинг Стандарт

Погода и прогноз

  • Карточки с температурой, осадками, влажностью, давлением, ветром
  • UV-индекс, видимость, «ощущается как», время восхода/заката (sunrise/sunset)
  • Прогноз на 5 дней с иконками погоды
  • Обновление каждые 30 минут

UV-индекс

  • Шкала 0–11+ с цветовыми зонами
  • Рекомендации по защите от ультрафиолета

Радиационный фон

  • Единицы: мкЗв/ч
  • Статусы: Normal / Warning / Danger
  • Норма: 0.05–0.1 мкЗв/ч

Качество воздуха (AQI)

  • Шкала 0–500
  • Параметры: PM2.5, PM10, CO, NO₂
  • Рекомендации по здоровью

Исторические данные

  • Графики за 24 часа
  • Сравнение влажности, температуры, давления

Пульс сервера

  • Latency (задержка ответа)
  • CPU, RAM, Disk, Uptime

Технические детали

  • Кэширование API-ответов: 15 минут
  • Rate limiting для предотвращения злоупотреблений
  • Дата/время с часовым поясом Europe/Moscow

10. Системные функции Система

Аутентификация и авторизация

  • Три роли: admin, user, guest
  • Role-based access control (управление доступом по ролям)
  • Система пользователей: добавление, удаление, изменение роли и пароля

Настройки

  • IP сервера, сетевые интерфейсы, порт
  • Параметры сканирования сети
  • Настройки погоды (координаты, интервал обновления)
  • API-ключи

Резервное копирование и восстановление

  • Файловые бэкапы — рядом с исходными файлами (app.py.backup-*, devices.db.backup-*)
  • Бэкап/восстановление БД — страница «Система» (каталог /srv/backup-db)
  • Бэкап eMMC выполняется только при загрузке системы с eMMC и подключённом HDD: при загрузке с SD-карты (проблемы с eMMC / тестовый запуск) или без HDD копия eMMC не создаётся — панель показывает причину отказа
  • Аварийный доступ — restore-server.service (порт 8081)
  • Импорт настроек (JSON)

Экспорт данных

  • Экспорт в JSON и CSV
  • Экспорт истории курсов, событий, настроек

Rate Limiting

Ограничение количества запросов для защиты от злоупотреблений API.

Резервные копии

Бэкапы хранятся рядом с исходными файлами и в /srv/backup-db (системный раздел {{ hf.root_kind_label }}). Рекомендации:

  • Перед любым изменением app.py — бэкап: cp /opt/lan-discovery/app.py /opt/lan-discovery/app.py.backup-$(date +%Y%m%d-%H%M%S)
  • Бэкап БД вручную: cp /opt/lan-discovery/devices.db /opt/lan-discovery/devices.db.backup-$(date +%Y%m%d-%H%M%S)
  • Восстановление — из файлов .backup-* или через страницу «Система»

13. Решение проблем

Панель не открывается

  • Проверьте статус: systemctl status lan-discovery
  • Посмотрите логи: journalctl -u lan-discovery -n 50
  • Проверьте порт: ss -tlnp | grep 8080
  • Перезапустите: systemctl restart lan-discovery

Устройства не обнаруживаются

  • Убедитесь что устройства в одной подсети ({{ hf.subnet }})
  • Проверьте nmap: nmap -sn -PR {{ hf.subnet }}
  • Убедитесь что ARP-сканирование не блокируется файрволом

Погода не обновляется

  • Кэш погоды — 15–30 минут, обновляется при обращении к странице/шапке
  • Проверьте доступность API: curl "https://api.open-meteo.com/v1/forecast?latitude={{ hf.lat|round(1) }}&longitude={{ hf.lon|round(1) }}¤t_weather=true"
  • Посмотрите логи панели: journalctl -u lan-discovery -n 50

Бэкап БД не создаётся

  • Вручную: cp /opt/lan-discovery/devices.db /opt/lan-discovery/devices.db.backup-$(date +%Y%m%d-%H%M%S)
  • Проверьте место: df -h /
  • Бэкап со страницы «Система» пишет в /srv/backup-db

Ошибка синтаксиса Python

  • Проверка: python3 -c "import py_compile; py_compile.compile('/opt/lan-discovery/app.py', doraise=True)"
  • Восстановление из бэкапа: cp /opt/lan-discovery/app.py.backup-XXXXXX /opt/lan-discovery/app.py

Клонирование не запускается

  • Клонирование eMMC → SD отключено, пока система загружена с SD-карты — dd перезаписал бы работающую систему (на этой панели система: {{ hf.root_src }}, {{ hf.root_kind_label }})
  • Если система загружена с eMMC: нажмите «Проверить SD» и убедитесь, что разделы SD не смонтированы: {% if hf.sd_dev %}umount /dev/{{ hf.sd_dev }}*{% else %}SD-карта не обнаружена{% endif %}
    • {% if hf.emmc_dev %}
  • eMMC = /dev/{{ hf.emmc_dev }}
    • {% endif %}

14. FAQ

Как добавить IPTV-плейлист?

На странице «Система» → блок «IPTV» → введите URL m3u-файла → нажмите «Добавить».

Как добавить веб-камеру?

На странице «Система» или в разделе «Мультимедиа» → введите URL потока (RTSP/HTTP) → нажмите «Добавить».

Как добавить онлайн-радио?

В разделе «Приложения» → Radio → введите URL потока и название станции → «Добавить».

Как пользоваться калькулятором?

Откройте вкладку «Приложения» → Калькулятор. Переключайтесь между обычным и инженерным режимами кнопкой.

Как работает генератор паролей?

Откройте «Приложения» → Пароли → настройте длину и типы символов → нажмите «Сгенерировать». Пароли хранятся в зашифрованном виде.

Как добавить тестовый адрес для проверки сети?

На странице «Система» → блок «Сеть» → нажмите «Изменить» рядом с нужным адресом.

Как сделать полный backup системы?

Файловые бэкапы создаются вручную (см. раздел 12, «Резервные копии»), БД — через страницу «Система» или cp. Образ SD можно сделать утилитой dd на другой диск.

Как восстановить систему из backup?

Восстановление файлов — из .backup-* рядом с файлами; БД — через страницу «Система» («Восстановить БД»). Аварийный доступ — restore-server.service (порт 8081).

Как подключиться к серверу по SSH?

ssh root@{{ hf.primary_ip }} (пароль — от root-аккаунта; не храните его в открытом виде). Рекомендуется настроить SSH-ключи для безопасности.

Как перезагрузить сервер через веб-панель?

Страница «Система» → «Управление питанием» → «Перезагрузить». Подтвердите действие.

Как выключить сервер?

Страница «Система» → «Управление питанием» → «Выключить питание». После команды можно отключить кабель питания.

Где хранятся данные torrent-клиента?

/srv/downloads/ — загруженные файлы (системный раздел {{ hf.root_kind_label }}); конфигурация Transmission — в /etc/transmission-daemon/.

Как обновить панель?

Отредактируйте /opt/lan-discovery/app.py, затем: systemctl restart lan-discovery. Перед изменением обязательно сделайте бэкап!

Как играть в Змейку?

Откройте «Приложения» → Змейка. Управление: клавиши WASD или стрелки.

Как работает секундомер?

Откройте «Приложения» → Секундомер. Нажмите «Старт» для запуска, «Круг» для фиксации промежуточного времени, «Стоп» для остановки.

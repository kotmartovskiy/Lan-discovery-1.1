# Архитектура

## Общая схема

```
Браузер ── HTTP :8080 ──> Flask (app.py)
                             │
        ┌────────────────────┼──────────────────────┐
        │                    │                      │
   modules/*            Jinja2 templates        фоновые потоки
   (роуты/логика)       (base.html + ...)       и schedule-задачи
        │                                            │
        └─────────────── SQLite devices.db ──────────┘
                        JSON в /etc/lan-discovery/
```

## Точка входа — `app.py`

`app.py` — «сборщик»:

1. Инициализация: `Flask`, `CSRFProtect`, `SECRET_KEY` из `/etc/lan-discovery/secret.key`, логирование, соединение с `devices.db`.
2. Порядковая регистрация модулей (каждый экспортирует `register_routes(app)`):
   ```python
   from modules.auth import register_routes as register_auth_routes
   from modules.devices_routes import register_routes as register_devices_routes, start_scan_thread
   from modules.weather_routes import register_routes as register_weather_routes
   from modules.system_routes import register_routes as register_system_routes, service_state
   from modules.network_routes import register_routes as register_network_routes
   from modules.media_routes import register_routes as register_media_routes
   from modules.core_routes import register_routes as register_core_routes
   ```
3. Ручные роуты верхнего уровня: `/api/currencies`, `/monitoring`, `/inventory`, `/torrent`, `/apps/notes`, `/apps/passwords`, `/apps/filemanager`, `/apps/terminal`.
4. Фон: `schedule.every(6).hours` — курсы валют, `every(24).hours` — цены переработки; `start_scan_thread()` — сканирование сети.
5. `Flask-SocketIO` — события реального времени (живой прогресс долгих операций).

Общие помощники: `_cmd()` (запуск команд с таймаутом), `_cfg()` (чтение конфига), `page_data` (данные для шаблонов), `service_state()` (обёртка над systemd).

## Модули

Подробная таблица роутов — [Модули](https://github.com/kotmartovskiy/Lan-discovery-ARM/wiki/Модули).

| Модуль | Ответственность |
|---|---|
| `auth` | Вход/выход, `login_required`, `admin_required`, `can_edit`, роли, bcrypt |
| `devices_routes` | Скан LAN, `/`, `/device/<ip>`, имена устройств, история |
| `system_routes` | `/api/status`, health, диск, бэкапы, eMMC/SD-клонирование, `/system` |
| `network_routes` | Конфиг сети, пинг/DNS/порты/traceroute, WiFi, Bluetooth |
| `media_routes` | IPTV, радио, плеер, будильники, камеры, Transmission, DLNA/UPnP |
| `weather_routes` | `/weather`, `/api/weather-status`, МЧС-оповещения |
| `core_routes` | `/apps`, `/help`, `/currencies`, настройки, пользователи, заметки, пароли, файловый менеджер, игры |
| `currencies`, `recycling`, `inventory`, `monitor` | Парсеры и сервисные функции без роутов |

## Шаблоны

- `base.html` — каркас: шапка с часами, меню, **нижняя панель статуса** (CPU/RAM/сеть/SD/копирование), опрос `/api/status` каждые ~3 сек.
- `base_app.html` — упрощённый каркас для внутренних приложений.
- `templates/apps/*.html` — содержимое вкладок на странице `/apps` (подгружается через `<iframe src="/apps/nettools">` и т.п.).
- `games/*.html` — статические игры, отдаются роутом `/games/<path:filename>`.

Важно: `TEMPLATES_AUTO_RELOAD` выключен (debug=False) → **после правки шаблона нужен рестарт сервиса**.

## Данные

| Источник | Формат | Примеры |
|---|---|---|
| `devices.db` | SQLite | `devices`, `device_inventory`, `weather_observations`, `weather_hourly`, `weather_daily`, `weather_alerts`, `mchs_alerts`, `currency_rates`, `currency_history`, `recycling_prices`, `events` |
| `/etc/lan-discovery/*.json` | JSON | `users.json`, `settings.json`, `iptv-playlists.json`, `network.json`, `alarms.json`, `weather.json` |
| `/etc/lan-discovery/notes`, `secrets` | файлы | заметки и «секреты» пользователей |

Фоновые записи в БД делают **systemd-таймеры**, а не само приложение: `weather-update.timer` (15 мин), `env-data.timer` (4 ч), `backup-db.timer` (час), `update-iptv.timer` (04:15). Список — [Установка](https://github.com/kotmartovskiy/Lan-discovery-ARM/wiki/Установка).

## Безопасность и доступ

- Сессии Flask, CSRF-токены (Flask-WTF) — форма входа включает `csrf_token`.
- Декораторы: `@login_required`, `@admin_required`, `@can_edit`; роли `admin` / `editor` / `guest`.
- Некоторые эндпоинты (например, reboot, poweroff, управление пользователями) — только `admin`.

## Особенности реализации

- Рабочий процесс — dev-сервер Flask (`Running on all addresses (0.0.0.0)`), для продакшена можно поставить gunicorn за reverse-proxy.
- Долгие операции (клонирование SD, сканирование сети) выполняются в фоновых потоках, состояние отдаётся через `/api/.../status`.
- Само приложение слушает `0.0.0.0:8080`, поэтому доступно и по LAN-IP, и по IP WiFi-точки доступа.

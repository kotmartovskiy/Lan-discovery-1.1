# Обновление и откат

Два способа обновить код на работающей установке. Оба безопасны: перед
изменениями создаётся бэкап, после — проверка и контроль здоровья; при
сбое выполняется **автоматический откат**.

## Способ 1: `update.sh` (рекомендуется)

```bash
cd /opt/lan-discovery
sudo ./update.sh --from /path/to/new-code   # из каталога с новым кодом
sudo ./update.sh                            # git pull, если это git-репо
```

Цикл обновления:

| Шаг | Действие |
|---|---|
| backup | tar кода (app.py, core/, modules/, templates/, static/, games/, tools/, deploy/, requirements*, install/update/pytest, tests/) + `settings.json` + sqlite-бэкап `devices.db` → `/var/backups/lan-discovery/<YYYYMMDD-HHMMSS>/` (+ `meta.json` с git-rev); ротация по `--keep` (default 5) |
| apply | копирование из `--from` (файлы, которых нет в источнике, **не удаляются**) либо `git pull --ff-only` |
| verify | `py_compile` app.py + core/ + modules/ |
| pip | `pip install -r requirements.txt` (идемпотентно) |
| restart | `systemctl restart lan-discovery` |
| health | `GET /api/health` retry 30×2 с |

**Авто-откат:** если `verify` или `health` не прошёл — бэкап этого
запуска распаковывается обратно (код + settings + devices.db), сервис
перезапускается, health проверяется повторно; скрипт завершается с
ошибкой, но система остаётся работоспособной.

Флаги:

```bash
sudo ./update.sh --dry-run            # показать план, ничего не менять
sudo ./update.sh --from DIR           # источник кода
sudo ./update.sh --rollback           # откат к последнему бэкапу
sudo ./update.sh --rollback <TS>      # откат к бэкапу <TS> (имя каталога)
sudo ./update.sh --keep 10            # глубина хранения бэкапов
sudo ./update.sh --prefix DIR         # установочный каталог
```

Бэкапы:

```bash
ls -1 /var/backups/lan-discovery            # список (имя = момент бэкапа)
cat /var/backups/lan-discovery/<TS>/meta.json
```

## Способ 2: git pull (вручную)

```bash
cd /opt/lan-discovery
sudo ./update.sh --dry-run && sudo ./update.sh   # бэкап+проверки есть и здесь
# либо совсем вручную (без авто-отката):
sudo cp -r app.py app.py.backup-$(date +%Y%m%d-%H%M%S)
git pull origin main
venv/bin/python -m py_compile app.py && sudo systemctl restart lan-discovery
```

## Откат вручную

```bash
cd /opt/lan-discovery
sudo ./update.sh --rollback              # к последнему бэкапу
sudo ./update.sh --rollback 20260930-231719   # к конкретному
```

Откат восстанавливает код, `settings.json` и `devices.db` — **события и
устройства, добавленные после бэкапа, будут потеряны** (бэкап делается
за секунду до обновления, поэтому потери — максимум минута).

## Проверка после обновления

```bash
systemctl status lan-discovery
curl -s http://localhost:8080/api/health   # db.status=ok
```

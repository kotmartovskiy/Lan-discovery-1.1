# Установка и развёртывание

## Требования

- Orange Pi (Armbian/Debian), ARM64; развёрнуто на `192.168.3.234` (LAN) / `192.168.3.235` (WiFi AP)
- Python 3.10+ (на боевой машине — 3.12)
- root-доступ по SSH (`root@192.168.3.234`, пароль `1234`)
- Порт `8080` свободен

## Установка

```bash
cd /opt/lan-discovery
pip3 install -r requirements.txt
python3 -c "import py_compile; py_compile.compile('app.py', doraise=True)"   # синтакс-проверка
```

Зависимости (`requirements.txt`): Flask, Flask-SocketIO, Flask-WTF, bcrypt, requests, beautifulsoup4, schedule.

## Структура на сервере

| Путь | Назначение |
|---|---|
| `/opt/lan-discovery/app.py` | Точка входа, роуты `/monitoring`, `/inventory`, `/torrent` |
| `/opt/lan-discovery/modules/` | Слои: auth, devices, system, network, media, weather, core… |
| `/opt/lan-discovery/templates/` | Jinja2-шаблоны (`base.html` — каркас с нижней панелью статуса) |
| `/opt/lan-discovery/devices.db` | SQLite: `devices`, `weather_*`, `currency_*`, `events`, `device_inventory`… |
| `/etc/lan-discovery/` | `users.json`, `settings.json`, `secret.key`, `iptv-playlists.json`, `notes/`, `secrets/` |
| `/usr/local/sbin/` | `update-iptv.sh`, `update-iptv-one.sh`, `weather-update.py`, `backup-db.sh`, `backup-emmc.sh` |

## systemd

`/etc/systemd/system/lan-discovery.service`:

```ini
[Unit]
Description=LAN Discovery Web Panel
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/usr/bin/python3 /opt/lan-discovery/app.py
Restart=always
RestartSec=5
User=root

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable --now lan-discovery
systemctl status lan-discovery
journalctl -u lan-discovery -f
```

### Периодические задачи (таймеры)

| Таймер | Период | Что делает |
|---|---|---|
| `weather-update.timer` | 15 мин (+2 мин после загрузки) | `/usr/local/sbin/weather-update.py` → таблицы погоды в `devices.db` |
| `env-data.timer` | 4 часа | `/etc/lan-discovery/weather.json` — данные окружения |
| `backup-db.timer` | каждый час в :00 | `backup-db.sh` — копия `devices.db` |
| `backup-emmc.timer` | 04:00 | бэкап eMMC, `backup-emmc-test.timer` — тест восстановления |
| `update-iptv.timer` | 04:15 | `update-iptv.sh` — обновление IPTV-плейлистов |

```bash
systemctl list-timers --all | head -20
systemctl start update-iptv.service    # ручной запуск разово
```

## Деплой изменений

### Автоматически

```bash
python deploy.py
```

Скрипт: подключается по SSH → создаёт бэкап `app.py.backup-<timestamp>` → заливает файл через SFTP → `py_compile` → `systemctl restart lan-discovery` → печатает статус сервиса.

### Вручную (регламент, обязательный)

1. Бэкап:
   ```bash
   cp /opt/lan-discovery/app.py /opt/lan-discovery/app.py.backup-$(date +%Y%m%d-%H%M%S)
   ```
2. Правка файла (SFTP/`remote_edit.py`).
3. Проверка синтаксиса:
   ```bash
   python3 -c "import py_compile; py_compile.compile('/opt/lan-discovery/app.py', doraise=True)"
   ```
4. Рестарт:
   ```bash
   systemctl restart lan-discovery
   ```

> ⚠️ **Нельзя** перезапускать сервис во время клонирования SD (`dd`) — процесс будет убит.

## Проверка после установки

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8080/login   # ожидаем 200
curl -s http://localhost:8080/api/status | head -c 300
```

В браузере: `http://<ip>:8080` → страница входа → `admin`.
